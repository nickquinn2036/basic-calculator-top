# Nick Quinn's Retro Candy-Bar Calculator

A fully interactive, responsive dark-mode calculator web application built as part of **The Odin Project** curriculum. It features a nostalgic retro vaporwave aesthetic inspired by classic candy-bar palettes, complete with a dynamic canvas border stripe spiral.

## Live Demo
*Coming soon via GitHub Pages!*

## Features
- **Core Math Engine:** Complete support for addition, subtraction, multiplication, and division.
- **Dynamic Display:** Renders the active formula smoothly as you build it.
- **Chained Math Operations:** Correctly collapses multi-step equations sequentially (e.g., `12 + 7 - 1` calculates `19` on the fly before executing the next operation).
- **Interactive UI Polish:** Custom CSS Grid button structure featuring tactile hover and active-click scaling animations.
- **Input Error Safeguards:** Built-in division-by-zero protection alerts and single-decimal typing locks.
- **Premium Utilities:** Destructive backspacing step-undos and unified physical keyboard/numpad event mappings.
- **Secret Easter Egg:** Hidden traditional pager input trigger.

## Built With
- **HTML5:** Semantic layouts and structures.
- **CSS3:** Advanced CSS Grid, absolute layout scaling, and repeating custom linear gradients.
- **JavaScript (ES6):** State variables, DOM tree listeners, keyboard trackers, and mathematical routing.

## What I Learned
Through this project, I moved past writing simple loops and learned how to handle complex global user states, catch silent runtime edge cases, and design fluid layouts that match aesthetic design specs.
